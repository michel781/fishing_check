# 04. API 키 발급 가이드 (공공데이터포털)

> 결론: **공공데이터포털(data.go.kr) 인증키 하나**만 있으면 됩니다. 바다누리 키를 따로 받을 필요는 없습니다(조석예보 API가 공공데이터포털로 이전됨).

## 1. 개념 정리

| 용어 | 뜻 |
|---|---|
| **공공데이터포털** | 정부 기관(기상청, 국립해양조사원 등)의 데이터를 API로 제공하는 사이트. https://www.data.go.kr |
| **인증키(serviceKey)** | "이 요청은 가입한 누구의 것"임을 증명하는 **출입증 문자열**. 계정마다 **1개**가 발급되고, 신청한 모든 API에 같은 키를 씁니다. |
| **활용신청** | 출입증이 있어도 **API마다 따로 이용 신청**을 해야 그 API를 부를 수 있습니다. 신청하지 않은 API를 호출하면 `SERVICE_KEY_IS_NOT_REGISTERED_ERROR`가 납니다. |
| **Encoding / Decoding 키** | 같은 키를 두 형태로 보여줍니다. Decoding은 원문(`+`, `/`, `=` 포함), Encoding은 URL용으로 변환한 것(`%2B` 등)입니다. **이 앱에는 Decoding 키**를 넣습니다(코드가 알아서 변환). |
| **`DATA_GO_KR_SERVICE_KEY`** | 이 앱이 인증키를 읽는 **환경변수 이름**입니다. Vercel에 이 이름으로 키 값을 저장하면 서버가 꺼내 씁니다. 코드나 GitHub에 키를 직접 쓰지 않기 위한 방식입니다. |

```
[사용자 휴대폰] → [Vercel 서버: DATA_GO_KR_SERVICE_KEY 로 인증] → [공공데이터포털] → 기상청 / 국립해양조사원
                          ↑ 키는 서버에만 있고 브라우저로 나가지 않음
```

## 2. 발급 절차 (약 10분 + 승인 대기)

### ① 회원가입
1. https://www.data.go.kr 에 접속해 오른쪽 위 **회원가입**을 누릅니다.
2. 개인 회원으로 가입합니다(본인 확인 절차가 있을 수 있습니다).

### ② API 활용신청 — 아래 2개는 필수
각 API 페이지에서 **활용신청** 버튼을 누르고 다음처럼 적습니다.
- 활용목적: **웹 사이트 개발**
- 상세 설명: "바다낚시 출조 판단용 모바일 웹 서비스 개발 (물때·해상날씨 표시)"
- 상세기능: 전체 선택
- 라이선스 동의 → **활용신청**

| # | API | 링크 | 이 앱에서 쓰는 곳 |
|---|---|---|---|
| 1 | 기상청_단기예보 조회서비스 | https://www.data.go.kr/data/15084084/openapi.do | 바람·강수·기온·파고(1시간 단위, 3일) |
| 2 | 해양수산부 국립해양조사원_조석예보 | https://www.data.go.kr/data/15038991/openapi.do | 만조·간조 시각과 높이 |
| 2′ | **(2번 페이지가 없을 때)** 해양수산부 국립해양조사원_조위관측소 실측·예측 조위 조회 | https://www.data.go.kr/data/15142507/openapi.do | 1분 간격 예측 조위 → 앱이 만조·간조를 직접 계산 |

> 2번 "조석예보" 페이지가 "없는 페이지"로 나오면(폐지·이전 가능성) **2′를 신청**하세요. 앱은 2번 → 2′ 순서로 시도하고, 둘 다 안 되면 Open-Meteo 모델값을 씁니다. 포털 검색창에 "국립해양조사원 조위"로 검색해 보는 것도 방법입니다.

### ④ 키 확인
**마이페이지 → 데이터활용 → Open API → 활용신청 현황**(또는 "인증키 발급현황")에서 **일반 인증키(Decoding)** 값을 복사합니다.

### ⑤ 승인·반영 대기
- 대부분 **자동승인**이지만, 키가 실제로 동작하기까지 **1~2시간**, 기상청 API는 **최대 하루** 정도 걸릴 수 있습니다.
- 그 전에 호출하면 `SERVICE_KEY_IS_NOT_REGISTERED_ERROR`가 납니다. 정상이니 기다리면 됩니다.
- 개발계정 호출 한도는 API당 **하루 1만 건** 수준입니다. 이 앱은 서버에서 30분 캐시를 두므로 초기 운영에는 충분합니다.

### ⑥ Vercel에 넣기
1. Vercel → 프로젝트 → **Settings → Environment Variables**로 갑니다.
2. Key에 `DATA_GO_KR_SERVICE_KEY`, Value에 Decoding 키를 넣고 Environments는 Production·Preview를 고른 뒤 **Save**합니다.
3. **Deployments → 최신 배포의 ⋯ → Redeploy**를 누릅니다. 환경변수는 재배포해야 반영됩니다.

### ⑦ 확인
`https://<배포주소>/api/health`를 열어 확인합니다.
- `west.sources.tide`가 `"KHOA"`, `west.sources.weather`가 `"KMA"`이면 성공입니다.
- 아니라면 `notes`의 오류를 봅니다.

| 오류 메시지 | 원인 | 조치 |
|---|---|---|
| `SERVICE_KEY_IS_NOT_REGISTERED_ERROR` | 승인 대기, 또는 해당 API 활용신청 누락 | 1~24시간 대기, 신청 목록 확인 |
| `JSON 아님: <OpenAPI_ServiceResponse…` | 키 형식 오류(Encoding 키를 넣음 등) | Decoding 키로 교체 후 Redeploy |
| `LIMITED_NUMBER_OF_SERVICE_REQUESTS_EXCEEDS_ERROR` | 하루 호출 한도 초과 | 운영계정 신청(활용사례 등록) |
| `HTTP 403`/`404` (조석) | API 주소 변경 | `KHOA_TIDE_URL` 환경변수로 새 주소 지정 |

## 3. 키가 없는 동안에는?
지금 바로 배포해도 됩니다. 키가 없으면 앱이 자동으로 다음처럼 동작합니다.
- 날씨·파도·수온: **Open-Meteo**(무료 국제 예보 모델)
- 조석: Open-Meteo 해수면 모델, 그것도 없으면 천문 추정

화면 아래에 어떤 데이터를 썼는지 표시되고, 키를 넣고 Redeploy하면 공식 데이터로 바뀝니다.
