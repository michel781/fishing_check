# 홈 화면에 바로 추가 — 가능한 방법과 한계 (v1.9.1)

## 결론

| 환경 | 버튼 한 번으로 바로 추가? | 이유 / 구현 |
|---|---|---|
| 안드로이드 크롬·엣지, PC 크롬 | **가능** | 브라우저가 주는 설치 창(`beforeinstallprompt`)을 버튼에 연결. 누르면 '설치' 창이 바로 뜸 |
| 삼성 인터넷 | 크롬으로 넘겨서 가능 | 삼성 인터넷이 만드는 APK 는 Play 프로텍트가 차단 → 크롬으로 열어 설치, 또는 바로가기로 추가 |
| 새 크롬 (Web Install API 지원) | **가능** | `navigator.install()` 이 있으면 기다림 없이 바로 설치 창 |
| 아이폰·아이패드 (모든 브라우저) | **불가능 (애플 정책)** | iOS 는 웹사이트가 설치 창을 띄우는 기능 자체가 없음. 공유 → '홈 화면에 추가'를 사람이 눌러야 함 |
| 카카오톡·네이버 등 앱 안 브라우저 | 불가능 | 앱 안에서는 추가 기능이 없음 → 기본 브라우저로 열기 버튼 |

## 삼성 인터넷: "Google Play 프로텍트 · 안전하지 않은 앱 차단됨" (v1.9.2 해결)

삼성 인터넷에서 '설치'를 누르면 삼성 인터넷이 이 사이트용 APK 를 직접 만들어 설치하는데, 이 APK 가 옛 안드로이드 기준으로 만들어져
Play 프로텍트가 "이 앱은 Android 이전 버전에 맞게 개발되었으며…"로 차단해요. 사이트가 APK 내용을 바꿀 수는 없어서 다음처럼 막았어요.

- **매니페스트를 브라우저별로**: `/manifest.webmanifest` 를 라우트로 바꿔, 삼성 인터넷에는 `display: "browser"` 를 줌 → APK 가 아니라 일반 홈 화면 바로가기로 추가됨 (차단 안 됨). 크롬 등 나머지는 그대로 설치형.
- **삼성 인터넷의 설치 버튼은 크롬으로**: 버튼이 '크롬으로 추가'로 바뀌고, 크롬으로 연 뒤 추가하도록 안내. 크롬은 구글이 서명한 WebAPK 를 만들어 차단되지 않음.
- 이미 차단된 아이콘은 길게 눌러 삭제 후 다시 추가.

## 안드로이드에서 '바로 추가' 확률을 높인 방법

1. **설치 창 이벤트를 가장 먼저 받기**: `layout.tsx` 의 인라인 스크립트가 화면이 뜨기 전에 이벤트를 저장 (`window.__fcBip`).
2. **늦게 와도 기다렸다가 바로 띄우기**: 버튼을 눌렀는데 이벤트가 아직 없으면 최대 2.5초 기다렸다가 오면 바로 설치 창을 띄움 (버튼을 누른 직후라 브라우저가 창을 허용하는 시간 안). 버튼은 '준비 중…'으로 바뀜.
3. **Web Install API**: 지원 브라우저에서는 `navigator.install()` 로 바로 설치.
4. **준비됐으면 '바로 추가'로 표시**: 설치 창을 띄울 수 있는 상태면 버튼 문구가 '바로 추가'로 바뀜.
5. 그래도 안 되면 브라우저별 따라 하기 안내.

크롬은 사이트에 처음 들어오자마자는 설치 창을 주지 않을 수 있어요 (사이트를 잠깐 둘러본 뒤 허용). 이것은 크롬 정책이라 사이트에서 바꿀 수 없어요.

## 아이폰: 가장 쉽게 따라 하게

- 사파리 버전을 읽어 **iOS 26(사파리 26)부터는 ⋯ 버튼 → 공유 → 홈 화면에 추가**, 이전 버전은 **아래 공유 버튼(⬆︎)** 으로 안내를 바꿈.
- 안내를 닫으면 12초 동안 **눌러야 할 버튼 쪽을 화살표로 가리킴** (사파리 26: 오른쪽 아래 ⋯, 이전: 아래 가운데 공유, 아이패드·크롬: 오른쪽 위).

## 정말 '한 번 눌러 설치'가 필요하다면: 앱스토어 앱

### 안드로이드 — 플레이스토어 (추천, 준비 완료)
웹을 그대로 감싼 앱(TWA)을 올리면 플레이스토어에서 '설치' 한 번이면 끝나요. 사이트를 고치면 앱도 자동으로 바뀌어요.

1. Google Play 개발자 계정 (1회 25달러)
2. https://www.pwabuilder.com 에 `https://fishing-check.vercel.app` 입력 → Android → 패키지 생성 (패키지 이름 예: `app.vercel.fishing_check.twa`)
3. 생성된 서명 키의 SHA-256 지문을 Vercel 환경변수에 넣고 Redeploy
   - `TWA_PACKAGE_NAME` = 패키지 이름
   - `TWA_SHA256_CERTS` = `AB:CD:...` (플레이 앱 서명을 쓰면 Play Console → 앱 무결성의 지문도 쉼표로 추가)
4. `https://fishing-check.vercel.app/.well-known/assetlinks.json` 에 값이 보이면 성공 (이미 구현됨) → 주소창 없이 앱처럼 열림
5. 생성된 `.aab` 를 Play Console 에 올리고 심사

### 아이폰 — 앱스토어 (비추천)
웹을 감싼 네이티브 앱(Capacitor 등)이 필요하고, 애플 개발자 계정(연 99달러)과 심사가 필요해요. 웹을 그대로 감싸기만 한 앱은 심사에서 거절(가이드라인 4.2)될 수 있어 알림·위젯 같은 앱 전용 기능을 추가해야 해요.

### 쓰지 않은 방법
- **아이폰 구성 프로파일(.mobileconfig) 웹 클립**: 홈 화면 아이콘을 만들 수 있지만 '프로파일 다운로드 → 설정에서 설치 → 암호 입력'으로 단계가 더 많고, '서명되지 않은 프로파일' 경고가 떠서 이용자에게 불안감을 줌.
