# 경쟁 분석: 어신(UHSHIN) vs 피싱체크 — 그리고 우리가 이길 자리 (2026-09)

> 조사 방법: 웹 검색 결과(앱스토어 소개문, 언론 기사, 기업정보 사이트)만 사용. 이 환경에서는 앱스토어·어신 누리집을 직접 열 수 없어
> **평점·다운로드 수·최근 리뷰 불만은 확인하지 못했음** (추측으로 채우지 않음). 실제 앱을 설치해 1주일 써 보는 검증이 다음 단계.

## 1. 어신은 어떤 서비스인가

| 구분 | 확인된 내용 |
|---|---|
| 회사 | ㈜애쓰지마(SGMA), 2020년 4월 설립, 광주, 대표 임동현. 2020년 11월 '어신' 출시 |
| 규모 | 2021년 7월 기사 기준 "곧 10만 유저" (그 뒤 공개 수치는 못 찾음) |
| 투자·신뢰 | 시드 투자(와이앤아처, 브릿지스퀘어), 씨엔티테크 투자. '도시어부' 박진철 명인 투자, '입질의 추억' 김지민 대표가 비상임 이사로 자문 |
| 최근 | 2026년 G-유니콘 선정, 해양생태계 변화 예측·실시간 모니터링 국가 R&D 수행 |
| 자기 규정 | "수산생물 모니터링 기반 피싱 내비게이터 + 통합 부킹엔진 + 커뮤니티 커머스를 갖춘 토탈 피싱 플랫폼", "AI 트래블테크" |

**기능 4개 축**
1. **피싱 내비게이터**: 장기 기상예보, 바람·해류 지도, 타임라인별 포인트 컨디션, **대상어종별 입질 확률**(물때마다 물고기 둘레 띠 색이 바뀌며 희박·나쁨·보통·좋음)
2. **피싱그램**: 낚시인 전용 SNS
3. **파트너스(예약)**: 출조일·지역·어종·인원만 넣으면 전국 낚싯배 실시간 예약 (제주·고흥 등). 사업주용 '어신 파트너스' 앱 따로 있음
4. **경매몰**: 활동 등급 기반 추첨형 커머스 (자주 들어올수록 싸게 살 기회)
- 바다 + **민물** 통합

**돈 버는 구조(추정)**: 선박 예약 중개 수수료 + 커머스. 정보 기능은 사람을 모으는 입구.

## 3. 우리가 부족한 것 (냉정하게)

1. **커버리지**: 포인트 57곳. 물때앱은 500~1,420곳. "우리 동네가 없네" 하는 순간 이탈. **가장 큰 약점.**
2. **데이터 신뢰**: 공공데이터 키(`DATA_GO_KR_SERVICE_KEY`)가 없으면 추정·데모 값으로 돌아감. 운영 사이트에 키가 들어가 있는지 `/setup`에서 반드시 확인 필요.
3. **알림**: 황금타임·위험 경보가 핵심 가치인데 푸시가 없음 (캘린더 추가뿐).
4. **네트워크 효과**: 어신은 SNS·예약으로 사람과 사업자를 묶음. 우리는 사장님 조황도 서버 저장소 없이는 안 켜짐.
5. **수익 모델**: 쿠팡 제휴 외 없음.
6. **민물 없음**, **브랜드(명인·유명인) 없음**.
7. **예측이 맞는지 증명 못 함** — 단, 이건 어신도 공개하지 않음 → 기회.

## 4. 이길 수 있는 자리 (제안)

어신과 **같은 판(예약·SNS·커머스)에서 싸우면 진다.** 자본·사업자 네트워크·브랜드가 다 필요하고 이미 앞서 있다.
대신 어신이 "토탈 플랫폼"으로 넓어지면서 비워 둔 자리를 잡는다:

### 포지션: "처음 가는 사람도 실패하지 않는 출조 결정 — 근거와 안전까지"
대상: 입문자·가족·생활낚시(방파제·워킹) 층. 꾼(고수)은 어신·물때앱이 이미 잡고 있지만, 이 층은 **"가도 돼? 언제? 가서 뭘 어떻게?"** 를 한 번에 답해 주는 곳이 없다.

| 무기 | 왜 이긴다 | 지금 상태 |
|---|---|---|
| **① 적중률 공개** | 모든 앱이 "확률"을 말하지만 맞는지 공개하는 곳이 없음. 우리 조과 기록은 이미 기록 시점의 예측 점수를 함께 저장 → "80점 이상일 때 실제로 잡은 비율 ○○%"를 공개하면 신뢰로 역전 가능 | 데이터 구조 있음, 집계·공개 페이지 필요 |
| **② 안전을 브랜드로** | "위험하면 가지 말라고 말해 주는 앱". 가족·초보에게 결정적. 너울·간조 고립은 사고 원인 | 위험 게이트 있음, 해경·기상특보 연동으로 강화 |
| **③ 초보 풀스택 가이드** | 채비 치수·캐스팅·준비물 가격·낚시점 질문 대본까지 — 경쟁 앱에 없는 "현장 실행" 영역 | 구현 완료 |
| **④ 웹·검색·카톡 공유** | 앱은 검색에 안 잡힘. "신진도 우럭 물때", "을왕리 주말 낚시" 검색 → 포인트 페이지로 무료 유입. 카톡으로 동행자에게 링크 하나로 공유 | 페이지 구조 있음, 포인트 수가 병목 |
| **⑤ 낚시점과 손잡기** | 어신은 '배(선박)' 쪽. 우리는 동네 낚시점(미끼·채비 구매 + 최신 조황의 원천)과 무료 제휴 → 사장님 조황이 차별 데이터가 됨 | 조황 공유 기능 있음 |

### 실행 순서 (돈 안 드는 것부터)
1. **신뢰 기반 (1~2주)**: 공공데이터 키 확인, Upstash 연결(무료)로 서버 계정·조황 켜기, 이메일 인증(이번에 구현).
2. **커버리지 (2~4주)**: 국립해양조사원 조석 예보 지점을 기준으로 포인트를 자동 생성해 57곳 → 수백 곳. 포인트×어종 페이지로 검색 유입.
3. **알림 (2주)**: 웹 푸시(아이폰도 홈 화면에 추가한 웹앱은 iOS 16.4부터 지원)로 "즐겨찾기 포인트 황금타임 1시간 전", "주말 위험 경보".
4. **적중률 리포트 (조과 기록 수백 건 모이면)**: 점수대별 실제 조과 비율 공개 페이지 → 마케팅 메시지 "맞히는지 숫자로 보여주는 유일한 낚시 앱".
5. **낚시점 제휴 (상시)**: 사장님 무료 등록 → 조황 올리면 가게 노출. 나중에 유료 상단 노출이 수익 모델.

### 핵심 지표
- 출조 결정까지 걸리는 시간(홈 → 포인트 결정), 주간 재방문율, 조과 기록 수(= 적중률 데이터), 검색 유입 비율, 위험 경고 뒤 대체 포인트 선택률.
