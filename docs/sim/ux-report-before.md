| 높음 | P5 현장 사용자(오후 3시) | 포인트 | 다음 만조·간조까지 남은 시간이 없음 |
| 중간 | P1 주말 워킹꾼(태안·우럭) | 홈 | 첫 화면에 '이번 주말' 판단이 없음 — 주말 출조가 핵심 사용 순간 |
| 중간 | P2 가족 입문자(학꽁치) | 포인트 목록 | 포인트 검색창이 없음 (항구명으로 찾기 불가) |
| 중간 | P2 가족 입문자(학꽁치) | 포인트 목록 | 화장실·주차·초보 추천 같은 편의 필터가 없음 |

| 낮음 | PWA | 설치 | apple-touch-icon PNG 없음 (iOS 홈 화면 아이콘) |
| 정보 | P4 동해 루어꾼(너울) | 시뮬레이션 | 시뮬레이션 모드 미지원 버전 — 위험 시나리오 화면 점검 불가 |
