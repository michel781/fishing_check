## 근처 낚시점
- `GET /api/shops?spot=<id>` → 포인트 15km 안 낚시용품점(낚시터·실내낚시·카페 제외), 거리·주소·전화·지도 링크
- 데이터: **카카오 로컬 API**(`KAKAO_REST_API_KEY`, 좌표·반경 검색) → 없으면 **네이버 지역 검색**(`NAVER_CLIENT_ID/SECRET`) → 둘 다 없으면 카카오맵·네이버지도 검색 링크
- 가게 목록은 포인트별 7일 캐시. 폐업 가게가 있을 수 있어 "전화로 확인" 안내를 붙였습니다.
- 개발 환경에서는 카카오·네이버에 접속할 수 없어, 실제 가게 목록은 키를 넣고 배포한 뒤 확인해야 합니다.

### 카카오 REST API 키 발급 (무료)
1. https://developers.kakao.com → 내 애플리케이션 → 애플리케이션 추가
2. **앱 키 → REST API 키** 복사 → Vercel 환경변수 `KAKAO_REST_API_KEY` → 다시 배포
3. (같은 키로 "내 주변" 주소 표시도 카카오 지도로 더 정확해집니다)

## 사장님 조황 (고객 만족 흐름)
포인트 화면 → **🏪 근처 낚시점 · 사장님 조황**
1. 가까운 낚시점 + **📞 전화** 버튼
2. **전화·방문할 때 이렇게 물어보세요**: 날짜·포인트·요즘 어종·물때를 넣어 자동으로 만든 질문 5개 + 복사
3. **사장님께 들은 최근 조황(30일)**: 이용자가 "○○낚시 사장님이 요즘 방파제 끝 해질녘 들물에 우럭이 잘 나온대요"처럼 공유 → 다른 이용자가 출조 전에 확인
   - 누구나 읽기, 로그인한 사람만 쓰기, 쓴 사람만 지우기 (Supabase `shop_tips` 테이블, `supabase/schema.sql` 5번을 SQL Editor 에서 다시 실행)
   - 연락처 입력 차단, "참고용" 안내
