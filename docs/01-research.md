# 01. 리서치 — 서해·동해 바다낚시 타이밍 서비스

> 작성일: 2026-09-27 · 대상: 반응형 모바일 웹(PWA) "피싱체크(fishing_check)"

---

## 1. 문제 정의

낚시꾼이 출조 전에 확인하는 정보는 **여러 앱과 사이트에 흩어져** 있습니다.

| 확인하는 것 | 지금 보는 곳 | 불편한 점 |
|---|---|---|
| 물때, 만조/간조 시각 | 바다타임, 물때표 앱 | 시각만 나오고 "그래서 몇 시에 가야 하나"는 알려주지 않음 |
| 바람, 파고, 비 | 기상청 날씨누리 해상예보, Windy | 해상예보 구역 단위가 넓어 방파제 하나 단위로는 판단이 어려움 |
| 수온 | 바다누리, 국립수산과학원 | 어종별 적정 수온과 따로 비교해야 함 |
| 어종 시즌, 습성 | 블로그, 유튜브, 커뮤니티 | 정리된 곳이 없고 지역에 따라 다름 |
| 포인트(방파제, 갯바위) | 커뮤니티, 지인 | 내항/외항, 발판, 출입통제 여부 정보가 없음 |
| 금어기, 금지체장 | 해양수산부 공고 | 해마다 바뀜 |
| 실제 조황 | 선사 조황, 카페 | 시점과 신뢰도가 제각각 |

**핵심 인사이트:** 사용자는 "데이터"가 아니라 **"결정"**을 원합니다.
→ *"이번 주말 태안에서 우럭 잡으려면 토요일 04:30~07:00, 신진항 외항 방파제 끝이 제일 좋다. 단 일요일은 풍속 12m/s라 출조 금지."*

## 2. 경쟁·참고 서비스

| 서비스 | 강점 | 약점 / 우리가 파고들 틈 |
|---|---|---|
| **바다타임** (앱·웹) | 전국 약 1,400개 지역 물때, 바다날씨, 수온, 바다갈라짐, 조황 커뮤니티. 인지도 1위 | 정보 나열형이라 "몇 시, 어디" 추천이 없음. 광고가 많고 UI가 무거움 |
| **낚시GO** 류 앱 | 물때, CCTV, 예보를 한곳에 모음 | 앱 설치가 필요함. 어종·포인트 유형별 판단 로직이 약함 |
| **기상청 날씨누리 해상예보** | 공식 예보 | 해역 단위라 거칠고, 낚시 관점의 해석이 없음 |
| **바다누리(KHOA)** | 조석, 조류, 수온, **바다낚시지수** 공식 데이터 | 전문가용 UI. 모바일 사용성이 떨어짐 |
| **Windy** | 바람·파도 시각화가 뛰어남 | 한국 물때, 어종, 법규 정보가 없음 |
| 선사 예약 플랫폼 | 선상낚시 예약, 조황 | 워킹(방파제·갯바위) 낚시꾼은 소외됨 |

**포지셔닝:** *"워킹·선상 낚시꾼을 위한 **출조 결정 엔진**. 물때, 날씨, 포인트, 어종 습성을 합쳐 **'골든타임'과 '갈지 말지'**를 알려준다."*
설치 없이 링크 하나로 공유하는 **모바일 웹**이라는 점도 차별점입니다(카톡 단톡방에 "이번 주 출조" 링크를 공유).

## 3. 도메인 리서치

### 3.1 서해 vs 동해 — 판단 로직이 달라야 함

| 항목 | 서해 | 동해 |
|---|---|---|
| 조차 | 매우 큼. 인천 기준 사리 때 8~9m, 태안·군산 4~7m | 매우 작음. 대부분 30cm 안팎 |
| 물때 영향력 | **최상위 변수**. 조류 세기와 물 흐림(탁도)을 좌우 | 영향이 약함. 조류와 해류(동한난류, 북한한류) 영향이 큼 |
| 핵심 날씨 변수 | 북서풍(겨울), 해무(봄·초여름), 탁도 | **너울**(먼바다 저기압에서 옴), 북동풍, **냉수대**(여름 용승) |
| 바닥 | 뻘, 모래, 여(암초) | 암반, 급심, 테트라포드 |
| 대표 워킹 어종 | 우럭(조피볼락), 노래미, 광어, 주꾸미·갑오징어(가을), 감성돔, 학꽁치 | 볼락, 가자미, 황어, 학꽁치, 전갱이·고등어, 무늬오징어, 벵에돔(남쪽) |
| 대표 선상 어종 | 우럭, 광어, 참돔, 주꾸미, 갑오징어, 백조기 | 대구, 가자미, 방어, 참가자미, 한치·오징어(야간), 문어 |

→ **해역별 가중치 프로필**을 둡니다. 서해는 Tide 가중치를 높게, 동해는 Swell·WaterTemp 가중치를 높게 잡습니다.

### 3.2 물때 기초 (알고리즘 입력)

- **물때**: 음력을 기준으로 조석 주기를 나눈 명칭입니다. 서해는 **7물때식**, 남해는 8물때식을 많이 씁니다. 사용자 설정으로 바꿀 수 있어야 합니다.
- **사리(대조)**: 조차와 조류가 가장 셉니다. 선상 낚시에서는 채비 운용이 어렵고 물이 흐려질 수 있습니다. 반면 조류가 먹이를 실어 오는 갯바위 대물 포인트에는 좋은 경우도 있습니다.
- **조금(소조)~무시**: 조류가 약해 선상 바닥 낚시(우럭, 광어)가 편합니다. 대신 활성도는 떨어질 수 있습니다.
- **통설: 3~5물(또는 10~12물)** 전후가 "물이 적당히 가는" 날로 선호됩니다. 단, 어종과 포인트에 따라 다릅니다.
- **하루 안의 타이밍**
  - **물돌이**(만조·간조 정점) 전후 ±1시간: 조류가 바뀌면서 입질이 몰리는 경우가 많습니다.
  - **들물(밀물) 초·중반**: 방파제·갯바위 워킹 낚시의 황금 시간대로 알려져 있습니다(감성돔, 우럭, 노래미).
  - **썰물 끝(간조)**: 서해 얕은 연안은 물이 빠져 포인트가 사라집니다. 반대로 **바닥이 드러나는 곳은 고립(갯벌 고립) 사고 위험**이 있습니다.
- **조류 속도 근사**: 조위 곡선의 기울기(dh/dt)에 비례합니다. 12분의 1 법칙(rule of twelfths)으로 시간대별 흐름 세기를 추정할 수 있습니다(만조→간조 사이 3·4번째 시간대가 가장 셈).

### 3.3 포인트 유형별 특성

| 유형 | 특징 | 좋은 조건 | 위험 요소 |
|---|---|---|---|
| **내항** | 파도가 막혀 잔잔함. 수심이 얕고 탁한 편 | 바람이 강하거나 파고가 높을 때 대안. 야간 볼락, 학꽁치, 전갱이, 망둥어 | 선박 통행, 계류 줄 |
| **외항(방파제 외곽)** | 수심 깊고 조류 소통이 좋음. 대물 확률 높음 | 풍속 7m/s 이하, 파고 1m 이하, 들물 | 월파, **테트라포드 추락**(연안 사고 다발) |
| **방파제 끝(등대)** | 조류가 부딪히는 곳이라 회유어가 지나감 | 물돌이 전후 | 월파, 너울 |
| **갯바위** | 감성돔, 벵에돔, 참돔 등 대물 | 너울이 없고 파고 0.5~1m(적당한 포말) | **너울 고립, 미끄러짐**. 동해 너울 주의보 연동 필수 |
| **백사장·서프** | 원투(가자미, 보리멸, 백조기) | 파도가 약간 있을 때 | 이안류 |
| **선상** | 어종 선택 폭이 가장 넓음 | 풍속 10m/s 이하, 파고 1.5m 이하(출항 여부는 선장·해경 판단) | 출항 통제 |

→ 같은 날씨라도 **"외항은 X, 내항은 O"** 같은 **대체 포인트 추천**이 핵심 가치입니다.

### 3.4 날씨 변수와 낚시 영향 (경험칙 → 초기 룰)

| 변수 | 낚시 영향 | 초기 룰(조정 가능) |
|---|---|---|
| 풍속 | 캐스팅, 입질 파악, 안전 | 워킹 0~5 m/s 좋음 · 5~8 보통 · 8~10 나쁨 · 10+ 위험 |
| 풍향 | 맞바람/등바람, 포인트 방향 | 포인트마다 "등지는 풍향"을 저장해 맞바람이면 감점 |
| 유의파고 | 안전, 채비 안정 | 워킹 ≤0.5 좋음 · ~1.0 보통 · ~1.5 나쁨 · 1.5+ 위험(갯바위·외항 금지) |
| 너울(파주기 ≥8s) | 동해 사고 1순위 | 파주기 8초 이상 + 파고 1m 이상이면 갯바위·외항 **차단** |
| 기압 변화 | 하강 직전 활성, 급하강 후 저활성(통설) | 3시간 기압 변화 −2hPa 이상은 가점, 저기압 통과 직후는 감점(약한 가중치) |
| 강수 | 민물 유입으로 염분·탁도 변화 | 전날 30mm 이상 폭우면 하구·내항 감점 |
| 수온 | **어종 활성의 핵심** | 어종별 적정 수온 범위에서 벗어나면 감점, 급변(±2℃/24h)하면 감점 |
| 해무 | 안전(선박), 시야 | 시정 1km 미만이면 경고 |
| 일출·일몰 | 피딩 타임 | 해뜰녘·해질녘 ±1시간 가점 |
| 달(월령) | 야간 어종(볼락, 한치, 갈치 등) | 그믐 전후는 집어등 효과가 크고, 보름은 워킹 볼락 저조(통설, 약한 가중치) |

### 3.6 법규·안전 (서비스 신뢰도의 기본)

- **금어기·금지체장**: 「수산자원관리법 시행령」에 따라 해마다 바뀌고, 지역별 예외가 있습니다. 비어업인(낚시인)이 어기면 과태료 대상입니다. 하드코딩하지 않고 **관리자 데이터로 운영**하며, 해양수산부의 연간 공지를 근거로 매년 갱신합니다.
- **낚시 금지구역·출입통제구역**: KHOA가 공공데이터포털에 「낚시금지구역」 파일 데이터를 제공합니다. 지자체와 해경의 연안 출입통제구역(테트라포드, 갯바위 일부)도 함께 반영합니다.
- **안전**: 테트라포드 추락, 갯바위 고립, 갯벌 고립, 너울 사고가 연안 사고의 대표 유형입니다. 점수보다 **안전 게이트**가 먼저 적용되어야 합니다.
- **면책 고지**: 예측은 참고 정보입니다. 출항 여부는 해경·선장 판단을 따르도록 명시합니다.

## 4. 데이터 소스

| 데이터 | 제공처 | 주기 | 용도 |
|---|---|---|---|
| **조석예보(고·저조 시각, 조위)** | 국립해양조사원(KHOA) 바다누리 OpenAPI / 공공데이터포털 | 일 1회 수집(예측값이라 수개월 치 선수집 가능) | 물때, 골든타임 |
| 조위 관측 실측 | KHOA 조위관측소 | 10분~1시간 | 실측 vs 예측 보정 |
| 조류 예보 | KHOA | 일 1회 | 조류 세기 |
| **바다낚시지수** | KHOA 「바다낚시지수 조회」(공공데이터포털) — 주요 포인트, 어종별 5단계 지수 | 일 1~2회 | **벤치마크·초기값**, 콜드스타트 대응 |
| 해양관측부이 수온·파고 | KHOA 「해양관측부이 최신 관측데이터」, 기상청 「해양기상관측자료 조회서비스」 | 30분~1시간 | 실측 수온, 파고, 파주기 |
| 단기예보(동네예보) | 기상청 「단기예보 조회서비스」(격자 nx, ny) | 3시간(02, 05, 08…시 발표) | 풍속, 풍향, 강수, 기온(시간 단위, 글피까지) |
| 해상예보 | 기상청 해상예보(구역별 풍향, 풍속, 유의파고, 4~5일) | 일 수회 | 해역 단위 파고 |
| 중기예보 | 기상청 「중기예보 조회서비스」 | 일 2회 | 3~10일 개략 전망 |
| 특보 | 기상청 기상특보(풍랑, 강풍, 태풍) | 수시 | **안전 게이트** |
| 냉수대·고수온 속보 | 국립수산과학원 | 수시(여름) | 동해 여름 감점 |
| 일출·일몰, 월령 | 한국천문연구원 API 또는 자체 계산(suncalc) | 연 1회 | 피딩 타임, 음력 물때 |
| 낚시 포인트 | 공공데이터포털 「갯바위낚시포인트」, 「전국낚시터정보표준데이터」 + 자체 큐레이션 | 수시 | 포인트 DB |
| 낚시 금지구역 | KHOA 「낚시금지구역」 파일데이터 | 분기 | 지도 표시, 경고 |
| 금어기·금지체장 | 해양수산부 공고 | 연 1회 이상 | 어종 카드 경고 |

> 공공데이터포털 API는 **일 트래픽 제한**(개발계정 기준 보통 1,000~10,000건)이 있습니다. 사용자 요청마다 호출하지 말고 **서버에서 배치로 수집·캐싱**하는 구조가 필수입니다. 운영계정 신청으로 한도를 늘릴 수 있습니다.

## 5. 타깃 사용자 (페르소나)

1. **주말 워킹꾼 "민수"(38, 수도권)**: 토요일 새벽 태안·안산 방파제에 갑니다. "갈까 말까, 몇 시에 도착해야 하나"가 최대 고민입니다.
2. **입문자 "지은"(29)**: 가족과 함께 학꽁치·망둥어를 노립니다. 안전하고 화장실 있는 내항이 필요합니다. 금어기와 체장을 잘 모릅니다.
3. **선상 매니아 "정호"(52)**: 주꾸미·갑오징어 시즌에 물때를 보고 선사를 예약합니다. 3~7일 앞 물때와 파고를 비교합니다.
4. **동해 루어꾼 "태윤"(33)**: 볼락·무늬오징어를 노립니다. 너울과 수온이 관심사이고, 야간 조과와 월령을 봅니다.
