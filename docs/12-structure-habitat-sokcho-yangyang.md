# 동해 북부(속초·양양) 내항 — 구조물·지형별 서식과 낚시 자리 (조사 2026-10-04)

조건: 초보 · 민장대 1대 + 원투 1대 · 갯지렁이, 오징어 살(염장 포함) · 10월 초 저녁·야간 · 설악항·물치항·낙산항 내항.
낚싯대 길이·바늘·봉돌 규격, 어종별 확률, 명당 순위, 고정 수심·거리는 일부러 넣지 않았다.

근거 표시: **생태**(공공·학술·백과) · **현장**(낚시 매체 기사·포인트 DB) · **추론**(자료로 확인 안 된 판단) · **규정**(법·조례).
조사 한계: 이 작업 환경에서 기사·기관 페이지를 직접 여는 것이 막혀 있어 웹 검색 결과 요약으로 확인했다(출처 목록에 "원문 미열람" 표시). 기사 다수의 게재일·조행일을 확인하지 못했다.

## 1. 원리 — 은신처·먹이·물 흐름

- **은신처**: 쥐노래미·우럭·볼락 같은 정착성 어종은 숨을 틈(테트라포드·석축·벽 기초)을 떠나지 않는다 → 구조물 바로 옆에서 낚인다. [생태 [1][4][5]]
- **먹이**: 구조물 표면엔 해조·홍합·따개비·작은 게, 모래 속엔 갯지렁이·작은 갑각류 → 돌 쪽은 쥐노래미, 모래 쪽은 가자미·보리멸. [생태 [1][6][15]]
- **물 흐름**: 고등어·전갱이·학공치 같은 회유어는 먹이 떼를 따라 다니며, 물이 통하는 방파제 끝·입구가 길목. 먹이 떼가 들어와야 내항까지 들어온다. [추론 + 현장 [14]]
- **발밑 vs 멀리**: 발밑은 방파제 기초(돌·블록)가 이어지는 정착성 어종 자리, 기초가 끝나고 평평한 모래로 바뀌는 먼 곳은 바닥을 뒤지는 어종 자리 → 민장대는 발밑 구조물, 원투는 멀리 모래. [추론]
- **등대**: 등대 불빛은 멀리 신호용이라 수면을 비추는 가로등과 다르다. '등대 주변'의 효과는 방파제 끝의 수심·조류·지형 꺾임으로 봐야 한다. [추론 — 직접 근거 문헌 없음]
- **자료 상충**: 우럭(조피볼락)은 "야간엔 움직이지 않고 물 흐름이 바뀌는 때 먹는다"는 기사[3]와 밤낚시 조과 통념이 다르다. 해질녘~초저녁 물돌이를 겹쳐 노리는 것이 양쪽과 충돌하지 않는다. [추론]

## 2. 구조물별 비교

### 1. 테트라포드의 수중 부분과 가장자리

| 항목 | 내용 |
|---|---|
| 대표 어종 | 쥐노래미, 볼락, 우럭(조피볼락) |
| 상주·회유 | 상주(정착성) |
| 모이는 이유 | 블록 사이 틈이 숨을 곳이 되고, 블록 표면에 붙은 해조·작은 갑각류가 먹이가 돼요. 파도도 틈 안쪽에서 약해져요. |
| 수층 | 바닥~중층의 틈 속. 볼락은 밤에 틈 위 중층으로 떠오르기도 해요. |
| 낮과 밤 | 쥐노래미는 낮 활동형(치어는 낮에만 먹음). 볼락 성어는 밤 활동형. 우럭은 자료가 엇갈려요(야간 비활동·물돌이 때 섭식 vs 밤낚시 조과 통념). |
| 민장대 | **조건부** — 올라가지 말고, 평평한 발판에서 닿는 테트라포드 가장자리 바로 앞에 수직으로 내려 바닥을 찍은 뒤 살짝 들어요. |
| 원투 | **부적합** — 끌어오는 동안 블록 틈에 걸려요. 원투는 다른 방향(모래)으로. |
| 미끼 | 갯지렁이(쥐노래미·볼락), 오징어 살(우럭 — 질겨서 잔챙이에 덜 뜯김) |
| 밑걸림·안전 | 밑걸림이 가장 심한 곳. 2020년 항만법 개정 뒤 테트라포드 등 위험구역은 출입 통제 대상 — 위로 올라가지 마세요. 빠지면 스스로 나오기 어려워요. |

근거: **생태** 쥐노래미는 암초·해조 바닥에 정착, 볼락은 테트라포드 틈·선착장·교각에도 삶. 테트라포드·자연초에서 노래미·볼락 어획이 많았던 연구(다른 해역). / **추론** 속초·양양 내항 테트라포드 가장자리에도 같은 원리가 적용될 것 — 이 항구들의 테트라포드 조과 기록은 확인 못 함. [1][4][5][3][16]

### 2. 내항 석축과 돌 틈

| 항목 | 내용 |
|---|---|
| 대표 어종 | 쥐노래미, 우럭, 볼락, 감성돔(석축 주변 기록) |
| 상주·회유 | 상주(정착성) + 감성돔은 계절 회유 |
| 모이는 이유 | 돌 사이 틈이 작은 은신처를 만들고, 돌에 붙은 해조·따개비·작은 게가 먹이가 돼요. 석축이 끝나는 곳(바닥과 만나는 선)에 먹이가 쌓여요. |
| 수층 | 바닥, 특히 석축 경사가 바닥과 만나는 선. |
| 낮과 밤 | 쥐노래미는 해 있을 때, 볼락은 어두워진 뒤. 해질녘은 둘이 겹치는 시간. |
| 민장대 | **적합** — 발밑 석축을 따라 바닥까지 내리고, 석축 끝선을 옆으로 조금씩 옮기며 찔러 봐요. 한자리에서 반응 없으면 몇 걸음 이동. |
| 원투 | **조건부** — 석축 기슭 너머가 모래로 이어지면 그 모래 쪽으로. 석축 위로 끌어올리면 걸려요. |
| 미끼 | 갯지렁이(쥐노래미), 오징어 살(우럭) |
| 밑걸림·안전 | 석축 경사면은 젖으면 미끄러워요. 평평한 상판 위에서만 서세요. 물치항 석축 주변은 감성돔 포인트로 소개됐지만 겨울 중심 기사예요. |

근거: **생태** 쥐노래미: 바위·돌에 배를 대고 생활, 세력권. 볼락: 암초·인공 구조물 틈. / **현장** 물치방파제: 감성돔은 큰·작은 방파제 콧부리와 석축 주변(감성돔 포인트 기사, 게재일 미확인). [1][4][9]

### 3. 수직 콘크리트 벽과 부두 기초

| 항목 | 내용 |

| 민장대 | **적합** — 벽에 붙여 바닥까지 내린 뒤, 반응이 없으면 한 뼘씩 올리며 층을 찾아요. 민장대가 가장 잘 맞는 곳. |

| 밑걸림·안전 | 어선이 대는 벽·계류줄 주변은 피하고 줄을 넘기지 마세요. 항만 안 어선·여객선 정박지는 항만법상 출입 제한일 수 있어요(현장 표지판 확인). |

근거: **생태** 볼락은 선착장·교각 같은 인공물에도 삶, 큰 개체가 아래·작은 개체가 위로 층. / **추론** 벽 기초 사석은 석축과 같은 은신 효과 — 세 항구의 벽 구조·기초 형태는 확인 못 함. [4][16]

### 5. 항구 안쪽 모래·펄 바닥

| 항목 | 내용 |
|---|---|
| 대표 어종 | 가자미류(참가자미 등), 강도다리(물치 내항 기록), 보리멸(10월엔 끝물일 수 있음), 양태·성대(10월 연안 출현 근거 부족) |
| 상주·회유 | 계절에 따라 깊은 곳↔연안을 오가요(완전 상주 아님) |

| 수층 | 바닥에 붙어 있어요. 미끼가 바닥에 닿아야 해요. |
| 낮과 밤 | 가자미류는 해 있을 때 입질이 많다고 알려져 있지만 밤에도 원투로 노려요. 양태는 낮에 모래 속 매복. |
| 민장대 | **조건부** — 발밑이 바로 모래면 가능하지만 닿는 범위가 좁아요. |
| 원투 | **적합** — 내항 모래 쪽으로 던져 바닥에 두고, 가끔 조금씩 끌어 위치를 바꿔요. 원투가 가장 잘 맞는 곳. |
| 미끼 | 갯지렁이(가장 잘 맞음). 오징어 살은 보조 |
| 밑걸림·안전 | 밑걸림은 적지만 폐어구·해초가 있을 수 있어요. 던지기 전 뒤·옆 사람과 배 다니는 길을 확인하세요. |

근거: **생태** 보리멸: 내만 모래, 겨울엔 깊은 곳·봄~가을 연안. 양태·성대: 모래·펄, 산란기 5~7월에 얕은 연안. 강도다리: 주로 동해 북부 모래·펄·자갈. / **현장** 물치방파제 내항 바닥은 대부분 모래라 원투에 적합(게재일 미확인). 물치 큰 방파제 내항 얕은 모래에서 강도다리·황어(출처 원문 미확인). / **추론** 보리멸·양태·성대의 10월 속초·양양 내항 조과 기록은 찾지 못했어요 — 대상어로 기대하지 마세요. [6][7][8][9][10][15]

### 7. 방파제 안쪽과 바깥쪽

| 항목 | 내용 |
|---|---|
| 대표 어종 | 안쪽: 쥐노래미·볼락·가자미류, 바깥쪽: 감성돔·회유어 |
| 상주·회유 | 안쪽 상주어 중심, 바깥쪽 회유어 섞임 |
| 모이는 이유 | 바깥쪽은 파도·조류가 직접 닿아 물이 잘 바뀌고 수심이 있어요. 안쪽은 잔잔하고 바닥이 모래·석축인 경우가 많아요. |
| 수층 | 안쪽 바닥 위주, 바깥쪽은 층이 다양해요. |
| 낮과 밤 | 북동풍·너울이 있는 날은 바깥쪽이 위험해지고, 안쪽이 대안이 돼요. |
| 민장대 | **적합** — 초보는 안쪽 평평한 발판에서. |
| 원투 | **적합** — 안쪽 모래 바닥 방향으로. |
| 미끼 | 갯지렁이, 오징어 살 |
| 밑걸림·안전 | 바깥쪽은 테트라포드·너울 위험. 물치 외항 테트라포드는 수면과 높이 차가 크다고 소개됐어요. |

근거: **현장** 물치항: 큰·작은 방파제 외항에서 감성돔, 파도가 적당히 있는 날 조과(겨울 감성돔 기사). 외항 테트라포드 높이 주의(에깅 기사). [9][11]

### 문어·오징어류 (물고기와 별도)

- **문어(대문어·참문어) — 노리지 마세요**: 바위틈 굴에 숨어 게·조개를 먹어요. 문어 전용 에기·테야 채비가 필요해 민장대·원투 + 갯지렁이·오징어 살로는 대상이 아니에요. 규정: 속초시는 조례로 시 수역 문어 낚시 금지(2024-06 통과, 시행 중 보도) → 설악항(속초)은 금지. 양양군 조례는 낚시어선 대상으로 보도 — 방파제 낚시 적용 여부 미확인. 강원 조례로 마을어장 안 비어업인 문어 포획 금지. 대문어 600g 이하 포획 금지. [17][18][19][20]
- **무늬오징어 — 현재 장비로는 부적합**: 해초가 있고 물이 잘 통하는 곳에서 작은 물고기를 쫓아요. 동해 북부 시즌은 6월 중순~11월 초로 소개됐지만 에기(루어)와 전용 낚싯대가 필요해요. 규정: 별도 금어기 확인 필요(서비스 어종 정보 참고). [12][11]
- **살오징어 — 현재 장비로는 부적합**: 밤에 불빛 주변으로 떠올라요. 오징어 뿔 등 전용 채비가 필요해요. 규정: 4~5월 금어기, 외투장 15cm 이하 연중 포획 금지. [21]

## 3. 현장 적용

1. **해질녘 전에 도착해 지형부터 본다** — 석축이 끝나는 선, 밝은 물색(모래)·어두운 물색(돌·해초), 가로등 위치, 배가 대는 곳·계류줄. 어두워지면 안 보인다.
2. **원투는 내항 모래 쪽에 먼저 넣어 둔다** — 배 길·계류줄·다른 사람 줄과 겹치지 않는 방향. 천천히 끌며 모래(사각사각)/돌(툭툭)을 구분하고, 경계를 찾으면 바로 모래 쪽에 둔다. 미끼는 갯지렁이 우선(모래 바닥 어종의 자연 먹이와 같음).
3. **민장대는 발밑 구조물을 훑는다** — 석축 끝선·벽 기초에서 바닥을 찍고 살짝 든 채 기다리고, 반응이 없으면 몇 걸음씩 이동. 정착성 어종은 은신처에서 멀리 나오지 않기 때문.
4. **어두워지면 민장대를 불빛 경계로** — 수면에 불빛이 닿는 선의 어두운 쪽, 얕은 층부터 한 뼘씩 내려가며 볼락 층을 찾는다. [추론]
5. **미끼** — 갯지렁이는 대부분에 맞고, 오징어 살은 질겨서 잔챙이가 많을 때·우럭에. 회유어용으로는 작게 자른다.
6. **하지 않을 것** — 테트라포드 위에 올라가기(항만법상 출입 통제 대상)[16], 어선·계류줄 주변, 항구 입구로 던지기, 속초시 수역 문어 낚시[17].
