# fishing_check 🎣 피싱체크

서해·동해 바다낚시 **출조 결정 엔진**을 담은 반응형 모바일 웹(PWA)입니다.
물때(만조·간조), 바다날씨, 수온, 포인트 유형(내항·외항·방파제·갯바위·선상), 어종 습성을 합쳐 **"언제, 어디서, 무엇을"** 낚을지 알려줍니다.

## 주요 기능

- **v1.13 시간대별 추천** (`/hourly`, 홈 '⏰ 시간대별 추천', 가장 잘 잡히는 포인트에서도 연결): 하루를 새벽(04–07)·오전·한낮·오후·저녁·심야(23–04) 6개 탭으로 나눠 시간대마다 가장 좋은 연속 2시간이 높은 포인트·어종 순위(포인트당 1어종, 위험·배 안 뜨는 시간·금어기 제외). 오늘/내일/모레·바다 선택, 지금 시간대 탭이 먼저 열림, 지난 시간대는 내일로 안내. 10분 공유 캐시
- **v1.12 오늘 밤 밤낚시** (`/night`, 홈 '🌙 오늘 밤 밤낚시 스팟'): 서울(또는 내 위치) 120km 안 밤낚시 포인트를 오늘 밤(일몰~새벽 3시) 실시간 예보로 순위 — 가장 좋은 2시간·들물 시간·바람·파도·체감온도·위험 판정. 방식(원투·루어·찌·가족) 선택, 24시간 유료 바다낚시터(정성·선재·만정) 오늘 밤 쾌적도, 영종도 삼목선착장·망둥어 추가
- **v1.11 앱 푸시 알림**: 설정 → 알림에서 켜기. 매일 새벽 5시 반 즐겨찾기 포인트의 오늘 황금타임·위험 예보(황금타임이 없으면 이번 주 더 나은 날), 선택 시 황금타임 30~90분 전 알림(GitHub Actions 30분 간격), 시험 알림. 아이폰은 홈 화면에 추가한 앱에서(iOS 16.4+). 필요: Upstash + `VAPID_PUBLIC_KEY`·`VAPID_PRIVATE_KEY`(/setup 에서 생성) + `CRON_SECRET`. 점검: `node scripts/push-e2e.mjs`
- **v1.10 회원가입 이메일 인증(무료)**: 가입 시 이메일로 6자리 인증번호(10분, 5회까지), 인증 안 하면 화면·서버 모두에서 가입 차단, 이메일 인증번호로 비밀번호 찾기. Gmail 앱 비밀번호(`GMAIL_USER`·`GMAIL_APP_PASSWORD`, 하루 약 500통 무료)만 넣으면 켜짐 (또는 Brevo·Resend). 저장소 없이 서명 토큰으로 동작. 경쟁 분석: `docs/11-competitor-eosin.md`
- **v1.9.1 홈 화면 바로 추가**: 안드로이드·PC 크롬은 버튼 한 번으로 설치 창(늦게 오는 설치 이벤트 대기, Web Install API), 아이폰은 사파리 버전별 안내 + 눌러야 할 버튼 화살표, 플레이스토어 앱(TWA)용 `/.well-known/assetlinks.json`. 한계와 방법: `docs/10-home-install.md`
- **v1.9 회원가입·로그인 바로 사용**: 키 없이도 가입·로그인·닉네임·비밀번호 변경·탈퇴가 동작(계정은 각 기기에 저장). Vercel → Storage → **Upstash for Redis** 를 연결하면 자동으로 서버 계정(여러 기기 동기화·사장님 조황 공유)으로 전환. 홈 상단 '로그인·가입' 버튼, 로그인 화면의 회원가입 버튼. 점검: `node scripts/account-e2e.mjs`
- **v1.6 어종 24종·낚시점**: 갈치·농어·벵에돔·삼치·부시리·숭어·전어·도다리·문어·붕장어·돌돔·오징어 추가, 포인트 근처 낚시점(카카오·네이버)과 전화 질문 자동 작성, 이용자가 공유하는 '사장님께 들은 최근 조황'
- **v1.5 전국 바다**: 전남·경남·부산·울산·제주 포인트 추가(남해 전용 계산 방식), 추가 이유 안내 팝업, 내 주변순에 '○○시 ○○동 근처' 주소 표시, 가장 잘 잡히는 포인트 화면 재설계
- **v1.4 회원가입·로그인**: 이메일(선택: 카카오) 가입, 약관·개인정보 동의, 즐겨찾기·조과 기록 기기 간 동기화, 내 계정·탈퇴 (Supabase, 키가 없으면 로그인 없이 동작)
- **채비 실제 치수**: 어종별 원줄·목줄·가지줄 호수와 길이, 가지 간격, 봉돌 호수, 찌밑 수심, 바닥에서 띄우는 높이를 치수선 그림·표로
- **채비 준비물 실시간 가격**: 쿠팡 파트너스 Open API(대체: 네이버 쇼핑) 가격·링크, 필수 준비물 합계
- **캐스팅·채비 움직임 영상**: 던지기(또는 배에서 내리기)부터 가라앉기·입질·챔질까지 채비 종류별 애니메이션 + 단계 자막
- **v1.3 디자인 시스템**: 홈·낚시터·포인트 상세·어종 목록/상세·내 기록·설정·도움말 8개 화면을 새 디자인 시스템(라이트 기본, 다크·자동 테마, 하단 5탭)으로 재구성. 포인트 사진 대신 SVG 풍경·어종 일러스트, 시간대별 낚시지수 막대, 물때 곡선, 현재 해황 타일, 하단 고정 길찾기·즐겨찾기 버튼
- **가장 잘 잡히는 포인트**(`/best`): 날짜·해역·유형·어종별 점수 높은 순 추천
- **카카오톡 공유 썸네일**: `public/og.jpg` (1200×630) Open Graph
- **어디 갈까 (홈)**: 해역(전체·서해·동해) × [오늘(남은 시간)·토·일] 상위 포인트 랭킹과 위험 경고
- **지금 카드**: 현장용 — 들물/썰물, 다음 만조·간조까지 남은 시간, 지금 점수, 진행 중·다음 골든타임
- **피싱 인덱스(0~100)와 골든타임**: 포인트 × 어종 × 1시간 단위로 점수를 매기고, 가장 좋은 연속 구간(최대 4시간)을 근거 칩과 함께 보여줍니다.
- **7일 출조 캘린더**: 날짜별 출조 판정(출조 추천 / 무난 / 비추천 / 위험)과 물때를 보여줍니다.
- **안전 게이트**: 강풍, 월파, 너울(파주기 8초 이상), 해무, 간조 고립 조건이면 점수를 제한하고 "위험"으로 표시합니다. 이때 **더 좋은 날**과 **인근 대체 포인트**를 추천합니다.
- **물때 계산**: 음력 날짜와 물때를 서버에서 직접 계산합니다. 7물때식과 8물때식을 설정에서 고를 수 있고, 월령·일출·일몰도 함께 계산합니다.
- **시간대별 차트**: 점수 막대와 조위 곡선을 함께 보여줍니다. 시간대를 누르면 세부 조건과 점수 구성을 볼 수 있고, 표 보기로도 전환할 수 있습니다.
- **어종별 점수 탭**: 그날 가장 점수가 높은 어종을 기본으로, 탭마다 점수·⚠·금어기 표시
- **포인트 찾기**: 검색, 초보·가족·화장실·주차·야간 필터, 가까운 순
- **캘린더 추가(.ics)**: 골든타임 90분 전 알림 / **용어·도움말**(`/guide`) / **안전 수칙** 카드
- **물고기별 낚는 법**: 미끼 먹는 모습(입질), 언제 낚아채는지, 채비 그림(SVG 6종), 따라 하는 순서, 처음 준비물, 흔한 실수, 안전, 영상 보기(YouTube) — 포인트 화면과 물고기 화면에서 제공
- **쉬운 말**: 중학생도 이해할 수 있게 화면 문구·점수 설명을 다듬음 (예: 들물 → "물 들어오는 중")
- **어종 도감**: 12종의 월별 시즌, 적정 수온, 선호 물때, 채비·미끼, 금어기·금지체장 경고를 담았습니다.
- **조황 기록**: 기록할 때 그 시각의 예측 점수를 함께 저장해 "골든타임 적중률"을 계산합니다. 사진(자동 축소)을 붙일 수 있고, 기록은 이 기기에만 저장되며 JSON으로 내보낼 수 있습니다.
- **PWA**: 홈 화면에 설치할 수 있고, 통신이 약한 곳에서는 마지막으로 받은 데이터를 보여줍니다. 설정에서 라이트·다크·자동(기기 설정 따름) 테마를 고를 수 있습니다.

## 실행

```bash
npm install
cp .env.example .env.local   # 키는 선택 사항
npm run dev                  # http://localhost:3000
npm test                     # 단위·시나리오 테스트
npm run simulate             # 엔진 대량 시뮬레이션 리포트 (docs/sim/engine-report.md)
npm run ux                   # 브라우저 UX 시뮬레이션 (서버 실행 필요, docs/06 참고)
npm run build && npm start
```

### 데이터 소스와 폴백

| 데이터 | 1순위 (키 필요) | 2순위 (키 불필요) | 최후 폴백 |
|---|---|---|---|
| 조석(고·저조) | 국립해양조사원 조석예보(공공데이터포털) `DATA_GO_KR_SERVICE_KEY` | Open-Meteo 해수면 모델 | 천문 추정 모델 |
| 바람·강수·기온 | 기상청 단기예보 `DATA_GO_KR_SERVICE_KEY` | Open-Meteo 예보 | 데모 값 |
| 파고·파주기·수온 | 기상청 파고(WAV) + Open-Meteo Marine | Open-Meteo Marine | 데모 값 |

어떤 소스를 썼는지는 화면 아래쪽에 표시됩니다. 추정 모델이나 데모 값을 쓸 때는 경고도 함께 표시됩니다.
`FISHING_OFFLINE=1`로 설정하면 외부 호출 없이 개발할 수 있습니다.

## 구조

```
src/
  app/                 Next.js App Router (홈, 포인트, 포인트 상세, 어종, 조황기록, 설정, API)
  components/          Timeline(점수·조위 차트), HomeClient, CatchLog, Settings …
  data/                spots.ts(베타 포인트 29곳), species.ts(어종 12종)
  lib/engine/          astro(음력·물때·일출몰), tide(조위 보간·극값·추정), score(점수·안전·골든타임)
  lib/providers/       khoa, kma, openMeteo, demo, index(폴백 체인·캐시)
  lib/sim/             scenarios(기상 시나리오 9종), mode(?sim= 시뮬레이션 모드)
scripts/               simulate.ts(엔진), ux-walkthrough.mjs(브라우저 UX), make-icons.mjs
public/                manifest, service worker, icon
docs/                  리서치·기획·구현 문서
```
