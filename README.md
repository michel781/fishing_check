# fishing_check 🎣

서해·동해 바다낚시 **출조 결정 엔진**을 만드는 반응형 모바일 웹(PWA) 프로젝트입니다.
물때(만조·간조), 바다날씨, 수온, 포인트 유형(내항·외항·방파제·갯바위·선상), 어종 습성을 합쳐 **"언제, 어디서, 무엇을"** 낚을지 알려줍니다.

## 문서

- [01. 리서치](docs/01-research.md): 문제 정의, 경쟁 서비스, 서해/동해 도메인 지식, 어종 습성, 법규·안전, 공공 데이터 소스
- [02. 서비스 기획](docs/02-product-plan.md): 기능 우선순위, 피싱 인덱스 알고리즘, IA·와이어프레임, 아키텍처, 데이터 모델, 로드맵, KPI, 리스크
