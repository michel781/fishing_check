# fishing_check 🎣 피싱체크

서해·동해 바다낚시 **출조 결정 엔진**을 담은 반응형 모바일 웹(PWA)입니다.
물때(만조·간조), 바다날씨, 수온, 포인트 유형(내항·외항·방파제·갯바위·선상), 어종 습성을 합쳐 **"언제, 어디서, 무엇을"** 낚을지 알려줍니다.

## 주요 기능

- **v1.22 채비 도감**: `/rigs`(더보기·도움말·장비 용어·어종 화면에서 연결). 채비 16종(바닥 가지채비·유동 봉돌 외바늘·선상 바닥·다운샷 / 반유동·전유동·막대찌 / 카드 / 지그헤드·노싱커·미노우·메탈지그·타이라바 / 에깅·봉돌+에기·오징어 뿔)을 그림·구성(위→아래, 용어 사전 연결)·원리·쓰는 법·장단점·실수·대표 어종으로 정리. 채비 고르기(장소·깊이·미끼), 한눈에 비교 표. 채비 그림에 노싱커·전유동·유동 봉돌·오징어 뿔 추가. 어종 화면 일치: 벵에돔 전유동(찌멈춤 없음), 돌돔 구멍봉돌, 오징어 뿔 그림. 기존 그림 글자 잘림 수정(루어, 타이라바). 데이터 `src/data/rigs.ts`
- **v1.21 바다낚시 장비·용어**: `/gear`(더보기·도움말·어종 목록에서 연결). ① 물고기를 잡는 6단계(던지기→깊이 맞추기→유혹→입질→걸기→끌어올리기)와 맡는 장비, ② 부분 이름 그림(낚싯대·스피닝 릴 9곳, 찌낚시 채비 연결 순서 9곳 + 원줄/목줄/찌밑 수심), ③ 장르별 장비 조합(원투·찌·루어·카드·선상, 채비 그림·핵심 용어·대표 어종), ④ 검색·분류되는 용어 사전 66개(역할·이유·요령·실수·함께 쓰는 용어·관련 화면), ⑤ 첫 장비 체크리스트. 사용자 제공 자료를 바탕으로 정리·보완(백래시는 주로 베이트릴, 플로팅 원줄은 찌낚시용 등). 채비 그림의 '낚싯줄'·'찌멈춤 매듭' 글자 겹침 수정. 데이터 `src/data/gearTerms.ts`
- **v1.20 어종별 릴 감기**: 어종 상세 '릴 감기' 탭(`/fish/{id}#reel`). 25종 한 주기(감기·저킹·폴링·끌기·고패·흘림·멈춤·기다림의 초·핸들 바퀴·바퀴/초) 리듬 막대, 속도 등급, 왜 이 속도인지(먹는 방식과 연결), 입질 뒤 감는 법·자주 하는 실수, 조건 보정(수온은 엔진의 tempFit, 밤·물살·바람), 내 릴 '1회전당 감기는 길이'로 cm/초 계산, 따라하기 코치(실시간 단계·바퀴 세기). 포인트 상세에 고른 어종의 오늘 조건 맞춤 요약. 값은 현장 통용 기준이며 낚시 방법 탭과 일치(참돔 1초 1바퀴, 볼락 1초 반 바퀴). 데이터 `src/data/retrieve.ts`, 로직 `src/lib/retrieve.ts`
- **v1.19 구조물별 서식 가이드**: `/structures`(도움말·포인트 상세에서 연결). 테트라포드·석축·수직벽·선착장 그늘·모래 바닥·암초·방파제 안/밖·방파제 끝·가로등 경계·모래-암초 경계 10개 환경을 대표 어종·상주/회유·이유·수층·낮밤·민장대/원투 적합성·미끼·안전으로 비교, 근거를 생태/현장/추론/규정으로 구분하고 출처 표기. 문어·오징어류는 따로(속초시 문어낚시 금지 조례 등). 설악항·물치항·낙산항 내항 포인트 추가(좌표 대략값, 확인된 정보·미확인 항목 분리). 모든 포인트 상세에 '구조물별 노릴 곳'(기사로 확인된 구조물 또는 포인트 종류 기준). 조사 문서: `docs/12-structure-habitat-sokcho-yangyang.md`, 데이터: `src/data/structures.ts`
- **v1.18 어종 먹이 습성**: 어종 상세에 '먹이 습성' 탭(`/fish/{id}#feed`, 포인트 상세 어종 카드에서도 연결). 25종 전부: 먹이 구성(%) 막대, 먹는 깊이(표층·중층·바닥) 단면 그림, 하루 먹이 활동 24시간 막대(밤 음영·지금 표시), 수온별 먹이 활동 곡선, 미끼 궁합(미끼가 흉내 내는 자연 먹이 비중으로 잘 맞음/보통/약함), 먹는 방식별 요령, 입질 모습, 철마다 먹성, 먹이가 비슷한 어종. 하루 활동·수온 곡선은 점수 엔진과 같은 식(`lightFit`·`tempFit`)을 써서 점수와 어긋나지 않음(엔진 결과 해시 동일 확인). 데이터: `src/data/feeding.ts`, 로직: `src/lib/feeding.ts`
- **v1.17.1 첫 화면·속도**: 포인트 상세에서 황금타임 상자를 점수 바로 아래로 올림(첫 화면에 보이게). 그날 남은 황금타임이 없으면 다음 좋은 날의 황금타임을 첫 줄에 안내. 점수 계산에서 어종과 무관한 물때 값을 포인트당 한 번만 계산하고 신월 계산을 캐시해 전체 순위 첫 계산 시간 약 20% 단축(결과 동일 확인). GitHub Actions 30분 예약 실행에서 홈·랭킹 데이터를 미리 계산(한국시각 00:05 포함, `FC_SITE_URL`만 있으면 동작).
- **v1.17 물때표**: 새 화면 `/tide`(홈 '물때표' 버튼, 포인트 상세 물 높이 표 아래 링크). 포인트별 날짜마다 만조·간조 시각·높이, 조차, 사리 정도 막대, 일출·일몰, 낮 시간 들물 구간, 그날 추천 어종 점수. 다음 사리·조금까지 남은 날, 한 달(5주) 물때 달력(7/8물때식 설정 따름). 포인트 상세 '시간대별 물 높이'에 고른 어종의 가장 좋은 시간·물 단계 요약과 그 시간대 '입질' 표시. 로직: `src/lib/tideCalendar.ts`

- **피싱 인덱스(0~100)와 골든타임**: 포인트 × 어종 × 1시간 단위로 점수를 매기고, 가장 좋은 연속 구간(최대 4시간)을 근거 칩과 함께 보여줍니다.
- **7일 출조 캘린더**: 날짜별 출조 판정(출조 추천 / 무난 / 비추천 / 위험)과 물때를 보여줍니다.
- **안전 게이트**: 강풍, 월파, 너울(파주기 8초 이상), 해무, 간조 고립 조건이면 점수를 제한하고 "위험"으로 표시합니다. 이때 **더 좋은 날**과 **인근 대체 포인트**를 추천합니다.
- **물때 계산**: 음력 날짜와 물때를 서버에서 직접 계산합니다. 7물때식과 8물때식을 설정에서 고를 수 있고, 월령·일출·일몰도 함께 계산합니다.
- **시간대별 차트**: 점수 막대와 조위 곡선을 함께 보여줍니다. 시간대를 누르면 세부 조건과 점수 구성을 볼 수 있고, 표 보기로도 전환할 수 있습니다.
- **어종별 점수 탭**: 그날 가장 점수가 높은 어종을 기본으로, 탭마다 점수·⚠·금어기 표시
- **포인트 찾기**: 검색, 초보·가족·화장실·주차·야간 필터, 가까운 순
- **캘린더 추가(.ics)**: 골든타임 90분 전 알림 / **용어·도움말**(`/guide`) / **안전 수칙** 카드
- **물고기별 낚는 법**: 미끼 먹는 모습(입질), 언제 낚아채는지, 채비 그림(SVG 6종), 따라 하는 순서, 처음 준비물, 흔한 실수, 안전, 영상 보기(YouTube) — 포인트 화면과 물고기 화면에서 제공
- **쉬운 말**: 중학생도 이해할 수 있게 화면 문구·점수 설명을 다듬음 (예: 들물 → "물 들어오는 중")
- **어종 도감**: 12종의 월별 시즌, 적정 수온, 선호 물때, 채비·미끼, 금어기·금지체장 경고를 담았습니다.
- **조황 기록**: 기록할 때 그 시각의 예측 점수를 함께 저장해 "골든타임 적중률"을 계산합니다. 사진(자동 축소)을 붙일 수 있고, 기록은 이 기기에만 저장되며 JSON으로 내보낼 수 있습니다.
- **PWA**: 홈 화면에 설치할 수 있고, 통신이 약한 곳에서는 마지막으로 받은 데이터를 보여줍니다. 설정에서 라이트·다크·자동(기기 설정 따름) 테마를 고를 수 있습니다.

## 실행

```bash
npm install
cp .env.example .env.local   # 키는 선택 사항
npm run dev                  # http://localhost:3000
npm test                     # 단위·시나리오 테스트
npm run simulate             # 엔진 대량 시뮬레이션 리포트 (docs/sim/engine-report.md)
npm run ux                   # 브라우저 UX 시뮬레이션 (서버 실행 필요, docs/06 참고)
npm run build && npm start
```

### 데이터 소스와 폴백

| 데이터 | 1순위 (키 필요) | 2순위 (키 불필요) | 최후 폴백 |
|---|---|---|---|
| 조석(고·저조) | 국립해양조사원 조석예보(공공데이터포털) `DATA_GO_KR_SERVICE_KEY` | Open-Meteo 해수면 모델 | 천문 추정 모델 |
| 바람·강수·기온 | 기상청 단기예보 `DATA_GO_KR_SERVICE_KEY` | Open-Meteo 예보 | 데모 값 |
| 파고·파주기·수온 | 기상청 파고(WAV) + Open-Meteo Marine | Open-Meteo Marine | 데모 값 |

어떤 소스를 썼는지는 화면 아래쪽에 표시됩니다. 추정 모델이나 데모 값을 쓸 때는 경고도 함께 표시됩니다.
`FISHING_OFFLINE=1`로 설정하면 외부 호출 없이 개발할 수 있습니다.
