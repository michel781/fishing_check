# fishing_check 🎣 피싱체크

서해·동해 바다낚시 **출조 결정 엔진**을 담은 반응형 모바일 웹(PWA)입니다.
물때(만조·간조), 바다날씨, 수온, 포인트 유형(내항·외항·방파제·갯바위·선상), 어종 습성을 합쳐 **"언제, 어디서, 무엇을"** 낚을지 알려줍니다.

## 주요 기능

- **피싱 인덱스(0~100)와 골든타임**: 포인트 × 어종 × 1시간 단위로 점수를 매기고, 가장 좋은 연속 구간(최대 4시간)을 근거 칩과 함께 보여줍니다.
- **7일 출조 캘린더**: 날짜별 출조 판정(출조 추천 / 무난 / 비추천 / 위험)과 물때를 보여줍니다.
- **안전 게이트**: 강풍, 월파, 너울(파주기 8초 이상), 해무, 간조 고립 조건이면 점수를 제한하고 "위험"으로 표시합니다. 이때 **더 좋은 날**과 **인근 대체 포인트**를 추천합니다.
- **물때 계산**: 음력 날짜와 물때를 서버에서 직접 계산합니다. 7물때식과 8물때식을 설정에서 고를 수 있고, 월령·일출·일몰도 함께 계산합니다.
- **시간대별 차트**: 점수 막대와 조위 곡선을 함께 보여줍니다. 시간대를 누르면 세부 조건과 점수 구성을 볼 수 있고, 표 보기로도 전환할 수 있습니다.
- **어종 도감**: 12종의 월별 시즌, 적정 수온, 선호 물때, 채비·미끼, 금어기·금지체장 경고를 담았습니다.
- **조황 기록**: 기록할 때 그 시각의 예측 점수를 함께 저장해 "골든타임 적중률"을 계산합니다. 기록은 이 기기에만 저장되고 JSON으로 내보낼 수 있습니다.
- **PWA**: 홈 화면에 설치할 수 있고, 통신이 약한 곳에서는 마지막으로 받은 데이터를 보여줍니다. 새벽 사용을 고려해 다크모드가 기본입니다.

## 실행

```bash
npm install
cp .env.example .env.local   # 키는 선택 사항
npm run dev                  # http://localhost:3000
npm test                     # 엔진·프로바이더 단위 테스트
npm run build && npm start
```

### 데이터 소스와 폴백

| 데이터 | 1순위 (키 필요) | 2순위 (키 불필요) | 최후 폴백 |
|---|---|---|---|
| 조석(고·저조) | 국립해양조사원 조석예보 `KHOA_SERVICE_KEY` | Open-Meteo 해수면 모델 | 천문 추정 모델 |
| 바람·강수·기온 | 기상청 단기예보 `DATA_GO_KR_SERVICE_KEY` | Open-Meteo 예보 | 데모 값 |
| 파고·파주기·수온 | 기상청 파고(WAV) + Open-Meteo Marine | Open-Meteo Marine | 데모 값 |

어떤 소스를 썼는지는 화면 아래쪽에 표시됩니다. 추정 모델이나 데모 값을 쓸 때는 경고도 함께 표시됩니다.
`FISHING_OFFLINE=1`로 설정하면 외부 호출 없이 개발할 수 있습니다.

## 구조

```
src/
  app/                 Next.js App Router (홈, 포인트, 포인트 상세, 어종, 조황기록, 설정, API)
  components/          Timeline(점수·조위 차트), HomeClient, CatchLog, Settings …
  data/                spots.ts(베타 포인트 26곳), species.ts(어종 12종)
  lib/engine/          astro(음력·물때·일출몰), tide(조위 보간·극값·추정), score(점수·안전·골든타임)
  lib/providers/       khoa, kma, openMeteo, demo, index(폴백 체인·캐시)
public/                manifest, service worker, icon
docs/                  리서치·기획·구현 문서
```
